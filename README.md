## Read and run

Open the full-code master notebook for the exercise definition and the full-code solution notebook for my implementation, results, and conclusions. GitHub displays notebook cells and saved outputs. Download an HTML export and open it in a browser to read the submitted report.

For a fresh run, open the notebook in Jupyter or Google Colab, keep its datasets available, and follow its installation cells. Some notebooks were written for Colab and need their data paths adjusted locally. Saved outputs describe the original run; rerunning model training or generation can produce different results.

The automation notebook needs `OPENAI_API_KEY` and `OPENAI_BASE_URL` in the adjacent `config.json`, or through the environment as described in the notebook. The committed key is empty; use your own credentials locally. Medical Assistant includes local model experiments that can be slow on a CPU.
